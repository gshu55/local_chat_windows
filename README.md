# LocalChat for Windows

LocalChat 是 Windows x64 上的局域网聊天和文件传输工具。两台电脑可以直接互发文字、图片、文件和文件夹，也可以邀请多台设备加入群聊。聊天记录保存在自己的电脑上。

## 下载

打开最新发布页，下载 `LocalChat-版本号-windows-x64-setup.exe` 并双击运行。安装后可从开始菜单打开 LocalChat。[最新 Windows 安装包和发行说明](https://github.com/gshu55/local_chat_windows/releases/latest)

## 开始使用

在同一局域网的两台电脑上打开 LocalChat。点击会话栏的「添加设备」，在独立页面查找附近设备，或粘贴对方的联系卡并核对设备指纹。双方确认信任后即可聊天。拖入文件或文件夹可发送附件，在编辑框中粘贴图片可图文混排。「设置 → 群聊」可创建群组。本机联系卡和连接优先级在「设置 → 我的设备」查看。

自己发送的消息和文件下方固定显示「未读／已读」，群聊显示已读、未读人数或「全部已读」。对方在前台会话中实际看到内容后才发送已读回执，双方都需要使用支持回执的版本。群消息不弹出送达人数提示，消息气泡旁不显示重发图标。待发的文字、图文、文件和目录邀请，会在对方上线、完成设备认证或群授权后自动补发，保留原消息 ID，重启后仍可继续。群聊仅补发给未送达的成员；已取消、撤回或本地移除的内容不会自动补发。

右键文字、图片或文件卡片选择「引用」，输入框会显示可取消的引用预览。发送后的引用卡片保留作者和摘要，点击可定位本会话中的原记录；原记录删除或撤回后仍保留引用摘要。

会话右键菜单提供「彻底删除联系人／群聊」。确认后清除本机聊天记录、草稿、搜索索引和传输记录，并停止相关收发。删除联系人同时取消信任，删除群聊后会拒绝原群 ID 的后续邀请。已保存到磁盘的文件和其他设备的记录保留。

群成员只需与群主互相添加并核验设备，收到群主签名授权后自动入群，无需逐一添加其他成员。聊天顶部显示群主和人数，点击「群信息」可查看完整名单与指纹。创建者担任群主，可改名、添加已认证联系人、移出成员、转让群主和解散群聊。转让由前任群主签名，已授权成员无需重新添加新群主；群主离线后，其余成员仍可直接收发群消息和文件。管理变更及邀请持久保存，离线设备恢复连接后自动补发。移出和解散后停止本群通信并保留只读历史；「彻底删除」只清除此设备的记录，已拒绝或彻底删除的群不会被重复邀请恢复。群授权不开放私聊，私聊仍需单独认证。所有成员请升级至 v0.1.11 或更新版本；旧群由群主进行一次管理操作即可生成新授权。

右键聊天中的图片，选「复制图片文件」后可直接粘贴到资源管理器，选「图片另存为…」可保存到指定目录。图文混排中的图片可逐张操作。打开大图后，按 Ctrl+C 可复制当前图片文件。

文件、文件夹和富文本原图优先通过 QUIC 传输。对方仅支持 HTTPS 或 UDP 不通时，应用会自动使用 HTTPS。下载中途切换可从上一个完整分片继续，群聊按成员分别协商。

## 设备发现与跨网段

新版通过所有可用网卡发送 IPv4 和 IPv6 组播探测，无需预先知道对方网段，也不要求本机配置目标 IPv4 网段的地址。设备回复联系卡后，聊天和文件传输通过系统路由直接连接。

跨路由器或 VLAN 自动发现需要网络支持组播转发；能通过单播访问对方，不代表组播也可达。网络无法转发组播时，可在「添加设备」页展开「跨网段查找」，补充多个网段或 IP。发现需要 UDP 42617，聊天和文件使用 TCP / UDP 42616。双方仍须独立核对指纹并确认信任。

## 手机网页传输

在电脑上打开「设置 → 手机传输」，开启「手机网页传输」。手机连入同一局域网后，扫码或在浏览器打开邀请链接即可加入。

电脑点「添加文件」，手机即可下载。手机点「选择文件」可多选上传，文件会保存到电脑的接收目录，同名文件自动另存。多部手机使用同一邀请时，可以下载彼此上传的文件。

网页传输默认关闭，使用局域网 HTTP 明文传输，适合可信 Wi-Fi。关闭开关后，邀请和下载链接失效，已经保存的文件会保留。

## 更新

从 v0.1.6 起，在「设置 → 软件更新」点「检查更新」即可查看下载进度。安装包校验通过后，LocalChat 会自动安装并从原目录重启，恢复未发送的草稿、草稿原图和待发附件。

使用 v0.1.5 或更早版本时，首次升级请下载安装包，从托盘菜单退出 LocalChat，再运行安装包。升级后会继续使用原有身份、设置和聊天记录。[历次版本和发行说明](https://github.com/gshu55/local_chat_windows/releases)

每个版本都附带 `latest.json`，其中列出本版安装包的下载地址、大小和 SHA-256。客户端从固定链接获取最新清单。[查看更新清单](https://github.com/gshu55/local_chat_windows/releases/latest/download/latest.json)
