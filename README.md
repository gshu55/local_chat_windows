# LocalChat for Windows

LocalChat 是 Windows x64 上的局域网聊天和文件传输工具。两台电脑可以直接互发文字、图片、文件和文件夹，也可以邀请多台设备加入群聊。聊天记录保存在自己的电脑上。

## 下载

- **安装版**　打开最新发布页，下载名为 `LocalChat-版本号-windows-x64-setup.exe` 的文件，双击运行。安装后可从开始菜单打开 LocalChat。[最新 Windows 版](https://github.com/gshu55/local_chat_windows/releases/latest)
- **免安装版**　将 ZIP 完整解压到一个文件夹，运行 `localchat.exe`。[下载免安装 ZIP](https://github.com/gshu55/local_chat_windows/releases/latest/download/LocalChat-windows-x64.zip)

## 开始使用

在同一局域网的两台电脑上打开 LocalChat。点击左下角个人资料栏，进入「设置 → 设备」，找到对方并核对设备指纹。双方确认信任后即可聊天。拖入文件或文件夹可发送附件，在编辑框中粘贴图片可图文混排。「设置 → 群聊」可创建群组。

## 更新

在「设置 → 软件更新」点击「检查更新」。发现新版后可直接选择对应的下载。升级前从托盘菜单退出 LocalChat，再运行新版安装包，或完整解压并替换免安装版的程序文件。原有身份、设置和聊天记录会继续使用。[历次版本和发行说明](https://github.com/gshu55/local_chat_windows/releases)

每个版本都附带 `latest.json`，其中列出安装包和免安装版的下载地址、大小和 SHA-256。客户端从固定链接获取最新清单。[查看更新清单](https://github.com/gshu55/local_chat_windows/releases/latest/download/latest.json)
